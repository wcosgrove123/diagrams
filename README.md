# Interactive Diagrams Repository

A collection of interactive HTML visualizations for curriculum theory, book notes, and miscellaneous explorations.

## Structure

```
.
├── curriculum-theory/    # Diagrams related to curriculum theory work
├── books/               # Visual notes and diagrams from books
└── misc/                # Random visualizations and experiments
```

## How to Use

### Adding New Diagrams

1. Place your HTML diagram files in the appropriate folder
2. Commit and push:
   ```bash
   git add .
   git commit -m "Add [diagram name]"
   git push
   ```

### Viewing Diagrams

All diagrams can be viewed directly in your browser using these preview services:

**HTMLPreview:** `https://htmlpreview.github.io/?https://github.com/wcosgrove123/diagrams/blob/main/[folder]/[filename].html`

**RawGit:** `https://raw.githack.com/wcosgrove123/diagrams/main/[folder]/[filename].html`
